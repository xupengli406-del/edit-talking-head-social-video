# 真人封面与发布材料

## 选人像

有明确选图就用准确那张/那一帧。用户“用这张”优先于旧版本选择；不要偷偷替换成相近表情或另一个生成脸。只有截图时，可从原片找对应的清晰帧，去掉播放器控件；确认姿态与表情一致，不能换成自己认为更美的别帧。

没有选图时，从本期录制选择清晰、眼神自然、表情与标题一致的帧。避开闭眼、说话造成的极端口型和运动模糊。必要时给少量有明显差异的候选，不铺十几个近似版本。真实肤质与身份优先；适度校色可以，过度磨皮、改骨相、动漫化和刻意精英商务感不默认采用。

## 文案与构图

先在现有制作说明中写清四项，再排封面：**主受众及处境 → 观看前的问题/期待 → 看完能得到的判断或方法 → 口播中能兑现的依据**。受众判断从完整成片出发，不凭主题热度或某一句金句推断。必要时读可用的 `ai-content-opportunity`，只借用当前需要的受众和收益判断，不为封面强制打分或重做选题。

封面表达“目标观众为什么值得点进来”，不能仅复述“视频讲了什么”或“我经历了什么”。先内部比较能被成片兑现的少量入口，再选择最直接的一个；可以是用途、选择依据、误解澄清、方法或认知变化，不把“价格反差”固定成默认。副标题只补必要信息，不夸大成片能交付的收益。用户已指定文字则准确使用，有明显歧义再提出具体调整。

个人观点或态度类口播也可采用“主题对象＋创作者明确结论”，以终为始，让观众为了解判断理由而观看；受众分析不等于强制问句、教程收益或中立选购标题。用户已确认的个人结论优先，保留其准确措辞；区分本人购买意愿与向所有人作购买保证，不虚构实测经历。

本用户默认采用已确认的“大字压真人”方向：自然近景本人，加清楚的人物外轮廓描边，厚重展示黑体直接叠在人像下半脸、肩胸区域，用主副字号和少量不同颜色形成层次。文字是第一阅读焦点，人物仍可辨；不再默认把标题挪进上方空白区或做成小字商务卡。读取可用的 `produce-big-title-cover` 落地排版与验收。

用户明确允许大字压在人像和部分脸上，无需再次确认；保留眉眼等身份锚点，不把整张脸盖没。人物描边沿真实外轮廓，字使用厚重而清楚的中文字体、适量深色描边和短阴影；用暖黄、暖白等少量颜色和大小对比区分主题、冲突、结果，不能所有字等大同色。参考图只取构图和字形气质，不替换成本图人物、不复制无关文案。

主题对象若是观众判断相关性的关键，应进入主要标题层级，不能缩成角落小标签。先在300—400像素宽下确认观众能同时认出“讲谁/什么”和“我为什么要看”，再决定主副字号。人物大、金额大都不能弥补主题对象读不清。

本期用户最终选择“启元机器人／这回真得买”，采用本人结论引出购买理由；此前“买回家能干啥？”只是用途问句方案，不能固化为本期偏好或通用模板。下一期仍判断内容类型与观看动机，允许观点先行。金额、起售价、版本和体验状态必须准确，发布会解读不能包装成已实测。

## 比例与像素

本用户后续封面默认只输出 **3:4 和 4:3**；不生成 9:16 或 16:9 封面，除非之后明确改要求。这是封面偏好，不改变口播视频的竖屏比例。每种比例独立调整人物位置、尺度、标题字号与行数；4:3重新编排，不能硬裁竖版或加空边。已有明确方向与双比例授权时直接完成两张，不重复索要样张批准。

照片需要等比铺满时用覆盖裁切并保护脸，不能拉伸或留意外边条。合理的构图呼吸空间可以保留，但不能用大片空白掩盖横版没设计。检查画布最外侧、字体阴影、裁切边界和平台可能截取的中心区域。

最终封面优先高分辨率 PNG；3:4 可按 2484×3312，4:3 可按 3200×2400 或 2880×2160 制作，这是建议尺寸而非平台硬门槛。受限于上传限制时再调整。文字在目标分辨率直接绘制，不能只把低清整图放大后叫高清；照片细节仍取决于源片。

同时检查原尺寸和约 300–400 像素宽缩略图。确认无意外留边、标题完整、换行自然、脸不变形和表情合适；字形测量或人脸避让检查不能替代看图。

## 发布包

一套规范目录即可，名称以项目实际情况调整：

```text
项目/
  原始素材/       用户原件与必需输入
  制作工程/       唯一当前工程、素材依赖、时间映射和必要检查
  交付/
    主题.mp4
    字幕.srt
    封面/         仅所需比例
    发布文案.txt
    使用说明.md
  发布包.zip      需要打包交付时生成，与交付目录一致
  整理记录.md     有清理时维护同一份恢复索引
```

发布文案提供实际可用的标题、正文和适量相关话题词；封面标题、帖子标题不必逐字一致，但不能换议题。不要伪造体验、数据或号召观众做没有在视频解释的操作。

使用说明简短交代哪个视频可发、封面比例、视频是否已烧字幕以及素材限制。视频已内嵌字幕时说明 SRT 用途，避免平台再叠一层。按需要预留平台声明或版权信息，不自作主张替用户作出与实际情况不符的声明。

包里不放调试图片、渲染日志、过期版本和源代码。整理源文件、修改交付内容或更换当前版本后，更新说明和 ZIP，并核对包内文件与交付目录完全相符。仅制作发布包时，不执行上传发布。
