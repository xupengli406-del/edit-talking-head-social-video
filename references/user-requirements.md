# 用户要求与审美

这是从实际选片和返修反馈归纳的个人制作规范。已确认的要求、只适用于某一期的选择、建议的制作方法分开记录。新要求可覆盖旧偏好，不把一次案例固化成所有视频的模板。

## 一、已经明确的要求

| 部分 | 用户明确表达的意思 | 制作时如何落地 |
| --- | --- | --- |
| 自然表达 | “说人话”“不像转述 AI 的回复” | 保留本人语气与原声；不把自然说话剪成逐字拼接，不用字幕改写成书面总结腔。 |
| 精剪 | “剪掉气口之类的” | 去冗长空白、失败开头、重说和重复铺垫；保留句意、情绪和转折需要的停顿。每个呼吸都删除并不是要求。 |
| 语速 | “稍微加速一下，听起来更自然” | 优先修剪停顿，再判断是否变速；轻微保音高，口型、字幕、动效一起对齐，不能机械套固定倍率。 |
| 内容价值 | “聊深一点”“有方法论或者操作步骤”“完全讲明白” | 需要改稿时交代概念边界、选择依据和能带走的做法；比较题按相关性说明使用差异及延迟、成功率、token 等成本。缺少实测不能编数字。录后剪辑不以无限扩写或重录为默认前提。 |
| 主题准确 | “只是举例子”“把我的创作工作流这个全片标注去掉” | 分清本期主题与举例；需要的范围补充在相关段落出现，不擅自换题或全片挂错误标签。 |
| 字幕 | 换行不舒服；倾向文字没有背景填充 | 按词组和意思断行，优先一至两行；普通字幕和普通标题无实色底板，用适量描边/阴影适应背景，避开脸和平台界面。 |
| 动效 | “更有网感”“这个是不是没做” | 必须在播放中感知到与内容有关的动作；仅改字体、轻微淡入或难察觉的缩放不能冒充完成了明显增强。 |
| 封面人物 | 要用自己选的那张脸，拒绝太丑、太卡通、太板正 | 保留身份和自然人像，尊重具体选中的帧/照片；真实、亲近、精神，比夸张修脸更重要。 |
| 封面设计 | “清晰直接”“还是要接地气一点” | 标题直接表达本期冲突或观看理由，层级明确，人物和文字共同构图；不靠高级感术语、花哨装饰或廉价卡通特效撑设计。 |
| 比例与清晰度 | 不接受难看的横版构图、意外留边、低分辨率 | 按实际需要的比例重新布局，照片等比适配；避免黑边/空栏、拉伸和裁脸，标题高分辨率重绘，手机缩略图仍好读。 |
| 完整交付 | “给我个发布包” | 视频、所需封面、字幕和发布文案集中交付，包内外一致，明确哪一个是当前可用版本。 |
| 版本整理 | “就这个了，其他处理掉” | 保留精确选中的成片、原始素材和一套当前工程；废弃试稿和过期包可恢复地移到系统废纸篓，不让用户反复整理。 |

## 二、不能误当成固定要求的案例

- **双人问答不是默认。** 用户曾尝试问答，后来改为单人口播。若本次明确做问答，提问站在小白立场，回答自然必要；结束要顺着对话收束，可感谢或引出下一期，不能硬插一个不合角色的问题。
- **美式商务照不是永久封面源。** 用户后来选过实拍视频帧。以本次明确选图为准；不要换回曾经喜欢过的另一张脸。
- **L 形、上下文字和弧形标题是候选布局。** 按人物位置和字数选，不要求每张都套。
- **不禁止 4:3。** 用户拒绝的是该横版的难看构图，不是所有横版。也不默认每期必须做三种比例。
- **1.10 倍速是本次案例。** 不是所有原片的标准速度；已经快的片子可以不加速。
- **黄色重点字是可沿用的风格起点。** 并非每一期必须黄黑大字、所有重点都放大。
- **本期的模块脱离、步骤推进、断线重连是成功的语义示范。** 下期应按新内容重新选视觉动作，不能无论讲什么都套接线流程。
- **去底板不是禁用所有有填充的形状。** 有信息作用的按钮状态、步骤进度、真实证据界面可以有背景；别把装饰色块铺在所有字幕后面。
- **高分辨率不代表有了新细节。** 例如 3:4 封面可按 2484×3312 重绘文字，原片人像的清晰度仍受源素材限制。

## 三、为了效果补充的制作建议

以下是可调整的起点，不是用户逐条指定的硬指标：

1. 先根据拍摄状态做判断：暗光、走路、近距离自拍先守住稳定和肤色；固定机位才考虑更明显的推近或局部放大。
2. 保留源片—成片的剪辑映射。删段或变速后统一重算字幕、图形、音效时间，避免后半段口型越来越不对。
3. 新风格先做 15–30 秒有代表性的内部样片；最好包含真实核心动作，而不只是片头。简单局部修改不强制重做样片。
4. 声音优先做轻度降噪、音量平衡和接缝处理；配乐非必需。提示音必须服务具体动作，并低于人声。
5. 对每个重点动效写清“原声锚点—动作前状态—变化—完成态”。成片 1×、手机大小仍看得出变化，才算解决了动效不足。
6. 最后分别检查文件、画面、声音和发布包。无法实际试听时明确记录未完成项，不拿波形检查替代听感。

审美判断用五句话概括：**像本人在说话；一眼知道看哪里；重点真的动起来；文字不挡人；封面真实直接。**
