# 字幕与可见动效

## 建立稳定版式

先看整段人物活动范围，给脸、字幕、图形和平台界面留位置。人物移动时不能只检查一帧。优先在原片空处放信息；空间不足就减少字数或用短暂的辅助画面，不把所有内容压在脸上。

白色正文与少量暖黄强调可作为延续风格的起点。普通标题和字幕默认透明背景，配细描边/柔和阴影适应明暗变化；避免厚黑字壳和反复出现的实色条。需要突出步骤状态、按钮或真实界面时可有功能性填充。字幕的位置、字号和对齐方式保持稳定。

## 字幕排版

- 逐句校对产品名、专有词、数字、否定词和语气，不直接信任自动转写。
- 一屏优先一至两行，按语义和实际字形宽度断开，不按固定字数硬切。“被迫离职”“桌面 Agent”等关键短语不拆成难读的碎片；不留下孤单字或标点另占一行。
- 通过分段、合理重排或减少同屏内容解决拥挤，不能只把字越缩越小。字幕忠于发言；画面概括与额外说明使用不同位置/层级，不混为同一句原声。
- 开始时间贴合发声，结束时间给阅读留余地但不拖到下一句话；动效标题与字幕别重复争抢同一位置。原声快、字多时优先保读完，不加逐字蹦跳。
- 在约手机显示尺寸下检查全片的短句、最长句、两行句和切换边界；安全区以实际构图和平台界面为准，不只看导出画布边界。

## 什么才算“做了动效”

用户要的是播放中明显可感知、帮助理解的变化。仅有静态字卡、很轻的透明度变化、极短的小幅缩放或代码里的动画声明，不足以证明完成了增强。

把值得动的内容变成状态：

| 口播语义 | 可以采用的视觉变化 | 完成态要让观众看懂 |
| --- | --- | --- |
| 少一个能力/模块 | 相关符号从一组中脱离，留下清楚缺位 | 缺的是哪一项 |
| 操作很绕/步骤很多 | 路径逐步推进，当前步骤接力高亮 | 到哪一步、为何繁琐 |
| 已连接/没接通 | 线段断开、接通，状态随之变化 | 两端关系发生了什么 |
| 前后差别/两种选择 | 并列、替换或局部展开 | 比较的具体维度 |
| 强烈反问/核心短句 | 短标题有明确入场或一次强调后落定 | 原声正在强调的意思 |
| 证据或操作细节 | 局部放大、遮罩聚焦、圈出相关处 | 证据本身仍可读 |

这是方法库，不是每条都用的模板。图形不能捏造真实产品界面、数字或能力；必要时明确是示意。

每个重点记录：**成片时间窗 / 原声锚点 / 唯一焦点 / 初始状态 / 动作 / 完成态 / 阅读停留 / 是否配短音效**。先设计完成态再决定如何进入，避免最后只剩乱飞的元素。

## 节奏建议与禁区

- 同一时刻只有一个主要变化。人物、字幕、大字和图形不要同时摇摆、缩放或抢视线。
- 按语义选重点，不按固定秒数强塞动画。普通话密集时画面更稳，复杂图形变化时给阅读时间。
- 可从约 0.3–0.7 秒动作、完成后至少约 1 秒可读停留起步；复杂流程需要更久，短强调可更快，以实播观感为准。
- 对近距离手持原片，优先让图形发生变化，不继续放大脸。固定机位才视需要加少量推近、切换构图或抠像。
- 不持续漂浮、呼吸缩放、故障闪烁或抖字幕；不靠无意义的烟花、贴纸和音效堆“网感”。也不要把克制误解成整片没有视觉事件。
- 开头直接建立本期核心问题，不默认长片头、无关片花或强迫三秒换场。结尾自然收束或保留原声提问，不补与本期无关的引流话术。

## 如何验收

实际导出有代表性的 15–30 秒片段，至少覆盖一个重点动作从前态到后态。片段可以来自中后部，不必只截开头；所有放置媒体与总时间线要真正截到测试区间，不能只缩短根容器时长。

以 1×、手机大小看：能否立刻指出动作发生在哪、它解释了什么、完成态能否读完。再检查动作前、中、后的连续帧，避免跳到终态、首次可见就已经完成、导出后动画失效等问题。静态截图可证明排版，不能证明运动顺畅。

用户反馈“看不出动效”时，先核对他看的是否当前文件，再检查实际导出；加强具体动作或重新选择视觉表达，不能只改名称为“增强版”。用户反馈太乱时，减少并发焦点、无意义动作和音效，保留真正解释内容的变化。
