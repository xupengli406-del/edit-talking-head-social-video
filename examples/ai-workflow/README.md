## 给了什么输入

作者面对镜头的真实随拍录像与原声，主题是用语音把想法交给AI。剪辑使用同一原片的17段真实发言，保留现场、表情和动作。

## 看到了什么结果

一条约45秒的竖屏口播：真人始终承担主要表达，加入中英双语字幕、关键词放大和与原话对应的简短图形。声音来自原片精剪，未合成新发言。

可留意前三秒怎样直接进入观点，以及人物动作、字幕强调和现场画面怎样配合。这条片表达作者的使用体验；需要看清电脑界面和操作步骤时，选择[电脑录屏与资料讲解](https://github.com/xupengli406-del/claude-skills/tree/main/edit-screen-tutorial-video)。
